心锚适格评定终端 0.6.10 更新说明

【修复】本机 Tcl/Tk 版本冲突导致无法启动
现象：启动后无任何界面，或在 日志\startup-error.log 中留下
      version conflict for package "Tcl": have 8.6.12, need exactly 8.6.14
原因：Tcl 要求「二进制 DLL」与「脚本库 init.tcl」版本必须完全一致。
      若机器上装有其它版本的 Tcl（例如 8.6.14），系统里的 tcl86t.dll 会被优先加载，
      而脚本库仍是随包的 8.6.12，两者不同源，Tcl 初始化时直接中止。
处理：启动时先固定随包的 Tcl/Tk 二进制与脚本库（二者同为 8.6.12），
      确保同源同版本，不再受系统里其它 Tcl 安装影响。

【说明澄清】
本程序自带 Python 与 Tcl/Tk 运行时，无需安装 Python 或 Node。
早期说明中"原生Windows程序"的表述容易引起误解：实际是由自带 Python 运行时打包而成，
界面依赖 Tcl/Tk。使用说明已同步更正。

其余功能与 0.6.9 一致，表格、规则、历史记录均保留。
