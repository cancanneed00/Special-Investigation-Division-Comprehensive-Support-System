【启动前必须停在哪个页面 —— 主界面（大厅）】
终端靠读取屏幕上的文字判断当前位置，所以运行前游戏必须停在「主界面（大厅）」，
也就是能看到右侧那一列功能入口的页面。示意如下（右侧这一列是关键）：

        ┌──────────────────────────────┬─────────┐
        │                              │  招  募 │
        │      游戏画面 / 角色立绘      │  补给站 │
        │                              │  事务所 │
        │                              │  探  员 │
        │                              │  心  锚 │
        └──────────────────────────────┴─────────┘

判定标准：屏幕上能同时看到「招募」「补给站」「事务所」，外加「探员」或「心锚」；
          屏幕右侧还能看到一排招募槽（显示“空闲”或“招募中”）。
          不同主题皮肤的按钮样式、文字位置会变，但只要这些入口文字在，就能识别。

以下页面都不行，终端会提示“未识别到主界面”：
  ✗ 启动器 / 登录页（有“开始游戏”“登录”之类按钮）
  ✗ 加载页、过场动画、登录奖励弹窗
  ✗ 任何二级页面：招募页、作战准备页、事务所内部、设置、活动页等
  ✗ 有弹窗没关掉（每日签到、公告、奖励领取等）——请先全部关闭再运行

已经停在主页但还是识别不到时，按下面顺序排查：
  1. 确认游戏窗口没有被别的窗口挡住，也不是最小化状态；
  2. 关掉全部弹窗，等 5～10 秒让画面完全静止后再运行；
  3. 刚进游戏时界面还在加载，此时识别容易失败——重启游戏、停在首页再运行最有效；
  4. 用了主题皮肤时按钮文字可能是艺术字（英文/花体），识别会变慢；
     反复失败请把该皮肤下的主界面截图发给作者，以便补充适配。

自动刷取前提：自动刷取任务，只适用于要刷取的关卡均已解锁的情况。程序不会代替你解锁关卡，也不会自动跳过未解锁的目标；只要目标关卡未解锁，刷取就会中断并按失败处理。开始前请先在游戏中确认要刷取的关卡已全部解锁，再运行对应任务。

适用于 Windows 10 / 11 64 位。已内置 Node.js 与识别资源，无需安装 Node.js 或 Python。需先启动《异象回声》PC 客户端并停在中文主页；只打开一个游戏窗口，终端与游戏权限保持一致。系统需具备 .NET Framework 4.5+、Windows PowerShell 和 Microsoft Visual C++ v14 x64 运行库。精简系统或缺少运行库的电脑可能需要补装，不能保证任何电脑完全免配置。
